# 🍿 Movie Recommender System — TMDB Dataset

A **content-based movie recommender system** that suggests 5 similar movies based on your selection. Built with **Python**, **Streamlit**, and **Scikit-learn**, powered by the [TMDB 5000 Movie Dataset](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata).

---

## 🎬 Features

- **Content-Based Filtering** — Recommends movies based on genres, keywords, cast, crew (director), and overview similarity.
- **Cosine Similarity** — Uses a cosine similarity matrix built from Bag-of-Words (CountVectorizer) to find the closest matches.
- **Real Movie Posters** — Fetches actual movie poster images from OMDb, Wikipedia, and TMDB APIs.
- **Modern UI** — Glassmorphism-styled dark theme interface built with Streamlit, featuring hover animations and gradient accents.

## 🚀 Getting Started

### Prerequisites

- Python 3.8 or higher
- pip (Python package manager)

### 1. Clone the Repository

```bash
git clone https://github.com/amurtyarai/movie-recommender-system.git
cd movie-recommender-system
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Generate the Model

Before running the app for the first time, you need to download the TMDB dataset CSVs into a `data/` folder and generate the model files:

```bash
python generate_model.py
```

> **Note:** This script expects `data/tmdb_5000_movies.csv` and `data/tmdb_5000_credits.csv` to exist. You can download them from [Kaggle](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata) or find them on public GitHub repositories hosting the TMDB 5000 dataset.

This will create:
- `model/movie_list.pkl` — Preprocessed movie list
- `model/similarity.pkl` — Cosine similarity matrix (~185MB)

### 4. Run the Application

```bash
streamlit run app.py
```

The app will open in your browser at **http://localhost:8501**.

## 🧠 How It Works

```
Raw CSVs ──► Merge & Clean ──► Feature Extraction ──► Vectorize ──► Cosine Similarity ──► Recommendations
```

1. **Data Merging** — `tmdb_5000_movies.csv` and `tmdb_5000_credits.csv` are merged on the `title` column.
2. **Feature Extraction** — From each movie, the following are extracted:
   - `overview` — Plot description (split into words)
   - `genres` — e.g., Action, Comedy, Drama
   - `keywords` — e.g., spy, superhero, based on novel
   - `cast` — Top 3 actors
   - `crew` — Director only
3. **Tag Creation** — All features are combined into a single `tags` string per movie.
4. **Vectorization** — `CountVectorizer` (max 5,000 features, English stop words removed) converts tags into numerical vectors.
5. **Similarity Computation** — Cosine similarity is calculated between all movie vectors, producing a 4806 × 4806 matrix.
6. **Recommendation** — When a user selects a movie, the app finds the 5 movies with the highest cosine similarity scores.

## 🖼️ Poster Fetching Strategy

The app fetches real movie poster images using a **multi-source fallback strategy**:

1. **OMDb API** (Primary) — Fetches high-resolution IMDb posters
2. **Wikipedia API** (Secondary) — Falls back to Wikipedia thumbnail images
3. **TMDB API** (Tertiary) — Uses The Movie Database poster images
4. **SVG Placeholder** (Fallback) — Generates a styled placeholder card if no poster is found
